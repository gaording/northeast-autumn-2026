# 向北，去秋天里 · 北京自驾版

2026年9月26日—10月2日，7天6晚，自家车从北京出发，暂按10月2日晚回北京。

[打开分享网页](https://gaording.github.io/northeast-autumn-2026/)

## 网页功能

`index.html` 包含全部样式、数据和脚本，直接保存文件即可离线打开。手机支持三路线切换、每日折叠、2–4人预算、准备清单、路线链接分享和打印／存为PDF。禁用脚本时可阅读A线完整行程与默认4人预算。

清单仅存当前浏览器。自驾版使用新的清单存储键，旧版的交通准备不会自动当作已完成。没有第三方统计、广告、定位或外部字体；点击地图和来源会前往外站。

## 日期与估算边界

中秋假期9月25—27日，第二天出发是9月26日；9月28—30日需要请假3天。日期官方来源在网页末尾。

每日公里数是城市／景区间估算，合计来自每天区间求和；小时为门到门预留，含部分休息、不含严重堵车。景区日只列私家车接驳，景区交通、排队和游览另占时间。具体酒店、停车场、导航路线和道路施工需临行重算。

预算按一辆自家燃油车、2–4人、两人一间、6晚住宿、7天餐饮，另加15%机动金。油耗假设8–10L/100km、油价假设8–9元/L，非实时油价；过路费保守预留、不扣假日减免。包括油费、过路费、停车、住宿、餐饮和门票预留；不含租车、车辆折旧维修、额外保险、购物和特殊房型溢价。纯电／混动车需重算。

同行人数、熟练司机人数、车型及10月2日是否必须回京尚待确认。天气、秋色、景区开放和天池可见均不保证，未做任何预订。

## 维护

- `trip-data.json`：三套完整自驾行程及逐日公里。
- `app.js`：交互与人均费用计算。
- `index.html`：独立完整页面。
- `build.py`：同步数据、默认路线静态正文、预算和脚本。
- `test_guide.py`：日期、公里合计、首尾北京、静态与嵌入数据一致性等检查。

```sh
python3 build.py
python3 test_guide.py
node --check app.js
python3 -m http.server 8769 --bind 127.0.0.1
```

GitHub Pages 使用 `main` 分支根目录。仅公开旅行内容，不含工作资料、登录凭证或本地研究文件。
