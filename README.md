# 向北，去秋天里

2026年9月26日—10月2日，东北7天6晚赏秋旅行手册。

[打开旅行网页](https://gaording.github.io/northeast-autumn-2026/) · [直接打开舒适版](https://gaording.github.io/northeast-autumn-2026/?route=easy)

## 两种走法

- A 三地全收集：加格达奇／阿里河 → 伊春 → 经哈尔滨转场 → 二道白河／长白山。覆盖大兴安岭、小兴安岭、长白山；两个主要转场日，须先落实交通，不是轻松游。
- B 舒适赏秋版：伊春 → 二道白河／长白山。减少一个区域，9月30日争取上山、10月1日留天气备用，不包含大兴安岭。

另有阿尔山＋南呼伦贝尔、漠河＋大兴安岭北线、长白山＋延吉＋长春三条替换思路，不建议叠加进本次七天行程。

## 使用

直接打开 `index.html` 即可，样式、路线数据和交互均内嵌，无需安装依赖。手机可切换路线、展开每日安排、估算2—4人预算和勾选准备清单；清单仅保存在当前浏览器。支持分享当前路线和打印／存为PDF。

禁用JavaScript时仍可读A版完整行程。无广告、定位、第三方统计或外部字体；只有点击外链才会访问外部网站。

## 日期与边界

中秋假期为2026年9月25—27日；第二天出发即9月26日，9月28—30日需请假3天。官方来源列在网页末尾。

出发城市、人数、驾驶安排、机票和具体列车尚未确认。所有车程是规划预留、预算是估算，未查询实时票额或做任何预订。出发前须确认交通、景区开放与天气；不能保证秋色或天池可见。日期按2026年9月15日已查到的公开资料规划。

## 修改与发布

- `trip-data.json`：两套行程的可编辑数据。
- `app.js`：浏览器交互源文件。
- `index.html`：可独立分享的完整页面，包含无脚本A版正文。
- `build.py`：将数据、A版静态正文和脚本同步到HTML，避免双份数据漂移。
- `test_guide.py`：结构、日期、链接与嵌入内容的一致性检查。

```sh
python3 build.py
python3 test_guide.py
node --check app.js
python3 -m http.server 8769 --bind 127.0.0.1
```

GitHub Pages 使用 `main` 分支根目录。只发布公开旅行内容，不包含工作资料、账号凭证或本地研究文件。
