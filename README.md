# 向北，去秋天里 · 十天分流版

[打开分享网页](https://gaording.github.io/northeast-autumn-2026/)

2026年9月26日从北京自驾出发，两人同行；10月2日对方回青岛，你留车继续到10月5日。暂按10月5日晚回北京、对方10月2日出发而非必须当日到家。前段是否能轮换开车仍未确认，两人不等于两位司机。

## 10月2日去青岛：候选分流，不是已出票方案

三条草案均10月1日晚到长春，2日留给对方离队；你当天在长春休整，不默认送站后赶长途。之后10月3日沈阳、4日锦州、5日北京，途中短游以体力和实际营业为准。

长春到青岛的10月2日航班、列车、直达/换乘、票额、价格和到达日期**尚未核实**。先查可接受的实际票，必要时改沈阳等离队城市并重排共同段，再订不可退酒店。机场和不同火车站不可混用；若必须10月2日到青岛，应先锁定当日抵达方案。没有预订或付款操作。

## 分段预算

页面可切换“你的费用 / 同行者费用 / 两人合计”，以及共同住宿一间或两间。

- 共同住宿：9/26—10/1共6晚，默认一间平分；只是估算假设，并非已约定的AA规则。
- 你独住：10/2—10/4共3晚，你独担。
- 餐费：你10天、对方7天。10/2驾驶和餐饮暂按全天共同段，实际离队时间确定后调整。
- 油费：共同段公里平分、单人段独担。按8–10L/100km与假设8–9元/L估算，非实时油价；纯电/混动车需重算。
- 过路费和停车：按两段里程中值比例粗分，非逐路段收费，未扣假日减免。
- 门票：共同景区各一份，你的单人短游另预留；所有合计另加15%机动金。

不含青岛机票/车票及抵达后的当地接驳、租车、车辆折旧维修、额外保险、购物等。页面“两人合计”也不是完整旅行总价。

## 使用与边界

`index.html` 内嵌样式、三套路线与脚本，可保存文件离线打开；没有广告、定位或第三方统计。手机可展开每日安排、切换路线与预算、勾选清单、分享当前路线、打印/PDF。无脚本时可读A线及你的默认预算。清单只保存在当前浏览器；分流版使用新的存储键，避免沿用过期的“交通已确认”。

中秋第二天为9月26日；9月28—30日需请假3天，假期官方来源在页面末尾。景点开放、天气、秋色和天池可见均不保证。公里与时长均为规划预留；单人疲劳时删游览或加住，不保证10月5日按时到家。

## 维护

- `trip-data.json`：三条10日路线，逐日阶段、公里、共同/单人里程。
- `app.js`：路线与预算交互；无外部请求。
- `build.py`：同步默认静态路线、预算、嵌入数据和脚本。
- `test_guide.py`：日期、30日卡片、10/2分流、10/5返京、里程、费用分摊守恒与静态一致性检查。

```sh
python3 build.py
python3 test_guide.py
node --check app.js
python3 -m http.server 8769 --bind 127.0.0.1
```
